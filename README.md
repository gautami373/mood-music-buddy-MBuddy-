# mood-music Music buddy
## 🛠️ Technologies Used
HTML5 – Structure and layout of the website.
CSS3 – Styling, responsive design, animations, and dynamic theme colors.
JavaScript (ES6) – Mood selection, language selection, dynamic song recommendations, and interactive user interface.
Google Fonts – Custom typography for a modern and elegant design.

## 📌 Conclusion

MBuddy is a simple and interactive mood-based music recommendation website that enhances the user's experience by suggesting songs based on their current mood and preferred type or language. The project demonstrates the use of HTML, CSS, and JavaScript to create a responsive and dynamic web application with changing themes and interactive content. It serves as a strong foundation for future enhancements such as music playback, Spotify API integration, user authentication, and personalized playlists, adding animeted interface and change daily interface will change system , it improves gen-Z listener intrest and hold attention also share playlist with friends .
